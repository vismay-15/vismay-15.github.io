Theory reference

Paris Law

da/dN = C · (ΔK)ᵐ

ΔK = Y·σ·√(πa). C and m are material constants. Larger ΔK → faster growth. Three regions: threshold → stable growth → rapid fracture.

Critical Crack Size

a_c = (K_IC / Y·σ)² / π

Fracture when a = a_c. Defines inspection detection limit for NDT per BS 7910.

HS2 Phase One

300 trains/day × 365 × 120 years ≈ 1.3×10¹⁰ cycles. All critical welds assessed by ECA using K_IC and Paris Law. Phased array UT must detect cracks ≥ a_c/3.
